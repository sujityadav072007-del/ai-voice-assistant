# Contributing

Thanks for taking an interest in Astra.

## Before opening a change

1. Keep the core text mode dependency-free.
2. Add or update unit tests for changed behavior.
3. Run `python -m unittest discover -s tests -v`.
4. Keep voice dependencies optional and document platform-specific setup.
5. Never use `eval` or execute arbitrary user-provided input.

Please describe the problem, the change, and the tests you ran in your pull request.
